- **상담 헤더 오른쪽에는 `공공 혜택` 버튼 하나만 둡니다**(`.ct-tool.key` — 브랜드 틴트 + 방패 아이콘 + 건수 뱃지). 상담 중 계속 열어 보는 도구라 눈에 띄어야 합니다.

- 4단계는 `.ct-steps`로 서로 링크돼 있어 실제로 이동합니다. 상담결과는 구분선 뒤에 따로 둡니다.

## 화면 상태 — 빈 값이 기본

**새로운 상담하기로 들어오면 모든 칸이 비어 있고 힌트만 보입니다.** 예시 값을 보려면 주소 뒤에 `?demo=1`을 붙입니다.
상담 리스트에서 기존 회차의 `결과 보기`를 누르면 `result.html?demo=1`로 열립니다.

마크업은 한 벌만 두고 `_state.js`가 `data-*` 속성으로 두 상태를 만듭니다.

| 속성 | 뜻 |
|---|---|
| `data-hint="예) 김민준"` | 빈 상태에서 보여 줄 힌트 (회색 `--ink-4`) |
| `data-demo="김민준"` | `?demo=1`일 때 채울 값 |
| `data-empty="—"` | 힌트 없는 칸의 빈 상태 표시 (기본 `—`) |
| `data-only="demo"` | 예시에서만 보이는 블록 |
| `data-only="empty"` | 빈 상태에서만 보이는 블록 |
| `data-advisor-only` | `?customer=1`이면 숨김 (설계사 전용) |

- 빈 상태에서는 세그먼트 선택·포커스 테두리·진행 막대·강조 색이 모두 풀립니다.
- 계산 화면(재무재표·상담결과)은 빈 상태에서 `.ct-blank` 안내 카드와 '적으러 가기' 버튼을 보여 줍니다.
- 상담결과의 **솔루션(설계사가 적는 칸)과 다음 상담**은 빈 상태에서도 적을 수 있게 힌트만 넣어 두었습니다.
- `?demo=1`로 열면 단계 이동 링크에 자동으로 `demo=1`이 붙어 예시 상태가 유지됩니다.

공용 자산은 repo 것을 그대로 씁니다. 이 폴더에 사본을 두지 않습니다.

```
../../styles/tokens.css      디자인 토큰 + Pretendard Variable
../../styles/concept-a.css   .cA 테이블 기본 · .bobi td.amt (금액 우측정렬)
../../styles/concept-e.css   .layout / .cE / .emain / .back-btn / .ft 푸터

```

## 화면별 메모

### 상담 리스트 (index.html)
- 내고객 목록(`customer/list.html`)과 같은 뼈대입니다: `.search-bar`(검색+정렬) → `.filter-bar`(필터) → `.list-panel`(`.table-head` + `.table-row`).
- 표 칸: 고객 · 회차 · 최초 상담 · 마지막 상담 · 다음 상담. **지역은 리스트에 넣지 않습니다**(고객 헤더에만 표시).
- **검색·정렬과 필터를 다른 줄로 나눴습니다.** 정렬은 검색바 오른쪽 `.sort-select`, 필터는 아래 `.filter-bar`의 라벨 붙은 pill 묶음입니다.
- 필터: 상태(전체 · 진행 중 · 다음 상담 있음 · 다음 상담 없음 · 상담일 지남) / 회차(전체 · 1 · 2–4 · 5 이상) / 최초 상담(전체 · 2026 · 2025).
  각 pill에 건수를 같이 보여 주고, 그 개수는 **'그 필터만 뺀' 나머지 조건 기준**으로 셉니다(누르면 0이 되는 칩이 안 생기게).
- 2회차 이상인 줄을 누르면 아래에 회차 목록(회차 · 날짜 · 결과 보기, 최근 순)이 펼쳐집니다. **회차별 결론 문구는 리스트에 넣지 않습니다.**
- 다음 상담 칸: 이어서 하기 / 일정 잡기(브랜드색), 상담일 지남(빨강).
- 데이터와 동작은 맨 아래 `<script>`의 `DATA`와 `render()`에 있습니다.

### 04 재무재표 (statement.html)
- 01–03에서 적은 내용을 **표로만** 모아 확인하는 화면입니다. 현금흐름표와 재무상태표(가진 것 / 갚을 것 / 순자산 + 막대).
- **원그래프는 여기 두지 않습니다.** 결과 맨 위에만 둡니다(기획 원칙).
- 각 표 오른쪽 위에 해당 단계로 돌아가 고치는 링크가 있습니다.

### 상담결과 (result.html)
- 상단 `.ct-subtabs`로 6개 블록을 오갑니다. 스크롤에 따라 현재 블록이 표시됩니다.
- ① 요약 — 흐름 문장 + **원그래프(5색 도넛 + 범례)**, 그 아래 정리: 왼쪽 고민·순자산 막대·목표 합계 / 오른쪽 솔루션(오늘의 결론 · 고민에 대한 오늘의 답 · AI 평가)
- ② 지출에 대한 결과 — 학원비 시나리오 막대(0 기준선 3줄)
- ③ 저축에 대한 결과 — 순자산 표 + 막대, 지금 모으는 39.5 vs 필요 130.6
- ④ 목표별 — **목표마다 얼마나 모았나(목표 3개 진행 막대)** · 돈이 몰리는 때 · 목표 적기 표
  - 목표 종류 6종(비상금·주택구매·결혼자금·자녀학비·노후·기타)은 **카드의 분류 칩과 표의 `종류` 열**로 씁니다. 종류별 빈 카드를 늘어놓지 않습니다.
  - 예시 데이터: 가족 여행(기타) 100/400 · 차 바꾸기(기타) 200/1,500 · 첫째 대학 등록금(자녀학비) 300/2,400
- ⑤ 혜택·보조금 3개 ⑥ 다음 상담(날짜 + 2·4·8주 뒤 + 달력)

### 혜택·보조금 (benefits.html)
- 상담결과 ⑤ 블록에서 펼쳐 보는 상세 화면입니다. `?from=<화면>`을 물고 와서 그 화면으로 돌아갑니다(기본값 상담결과).

## 표시 규칙 (기획 문서 4장 요약)
- 금액은 모두 만 원. 빈칸 = 모름, 0 = 없음. 모르는 칸이 있으면 합계 옆에 '모르는 N개 빼고'.
- 고객에게 보이는 말은 존댓말, 쉬운 말. '위험', '나쁨' 같은 판정 표현 쓰지 않음.
- 설계사 전용 칸(점선 테두리 + '상담 결과에는 안 나와요' 배지)은 고객 보기에서 숨김.
- 긴 이름(혜택명 · 기관명 40자 이상)은 2줄에서 말줄임.

## 이번 작업에서 정한 것 (2026-09-29)
- 사이트맵대로 4단계 끝을 **재무재표**로 두고, **상담결과를 별도 화면**으로 분리했습니다.
- **혜택·보조금은 상담결과 안의 블록**입니다. 상담 중에는 도구 버튼으로도 열립니다.
- 목표 **종류 6종(비상금·주택구매·결혼자금·자녀학비·노후·기타)**은 카드 분류 칩과 목표 적기 표의 `종류` 열로 씁니다. 시안의 목표 3개(가족 여행·차 바꾸기·첫째 대학 등록금)는 그대로 유지합니다.
- 다음 상담일은 상담결과 맨 끝에서 고객과 함께 정합니다. **기획 문서(04 상담 정리에 다음 상담일)와 다르므로 기획 쪽에 알려야 함.**
- 원그래프는 **상담결과 맨 위에만** 둡니다(시안 원칙 유지). 재무재표는 표만 씁니다.
