# 보비 모바일 디자인 기준

작성일 2026-11-27 · 적용 범위 모바일(≤960px) · 상태 **확정**
개정 2026-11-27 — 1-4 고정 요소 규칙에 하단 액션 바 허용 조항 추가
개정 2026-11-27 — 1-3·1-4 주요 CTA 를 하단 플로팅 버튼(FAB)으로 확정
개정 2026-11-27 — 1-4 검색·기간·필터를 한 줄로. 기간/필터는 아이콘 버튼

이 문서는 다섯 영역만 다룬다 — 글자 크기 / 간격·여백 / 버튼·터치 / 절제 UI / 데이터 표시.
색상, 모서리 둥글기, 그림자, 아이콘, 브랜드 요소는 기준을 정하지 않는다.

PC 기준값은 `styles/tokens.css`(라이브의 `/css/bobi/tokens.css`)를 그대로 쓴다.
글자 `--fs-h1 24 / --fs-h2 19 / --fs-body 15 / --fs-option 13`,
간격 `--s1~--s10 = 4·8·12·16·20·24·32·40·48·64`.

토큰 초안은 `styles/tokens.mobile.css` 에 있다. 아직 어디서도 불러오지 않는다.

이 문서는 **값과 근거**를 정한다. 화면을 만들 때 옆에 두고 볼 실무용 규칙·체크리스트는
[`mobile-ui-rules.md`](mobile-ui-rules.md) 에 있다.

## 1-1. 글자 크기

| 역할 | PC | 모바일 | 줄 간격 | 토큰 |
|---|---|---|---|---|
| 페이지 제목 | 24 | **20**, 1줄 | 1.3 | `--m-fs-page` |
| 섹션 제목 | 19 | **17** | 1.3 | `--m-fs-sec` |
| 목록 핵심 정보 (이름·제목) | 15 | **16** | 1.4 | `--m-fs-item` |
| 본문 | 15 | **15** | 1.5 | `--m-fs-body` |
| 보조 정보 (나이·담당자·보험사) | 13 | **13** | 1.4 | `--m-fs-meta` |
| 배지·캡션·날짜 | 13 | **12** (최소) | 1.3 | `--m-fs-caption` |
| 강조 숫자 (KPI·금액) | 24 | **20** | 1.2 | `--m-fs-kpi` |
| 버튼 — 주요 / 보조 | 13–15 | **16 / 14** | — | `--m-fs-btn` / `--m-fs-btn-sm` |
| 입력창·선택상자 | 13–15 | **16** (고정) | — | `--m-fs-input` |

규칙

- 이 단계 밖의 크기는 쓰지 않는다. 필요하면 토큰을 늘리고, `font-size: NNpx` 를 직접 쓰지 않는다.
- 12px 미만 금지.
- 한글 줄바꿈은 모바일 전역 `word-break: keep-all` (어절 단위). `overflow-wrap: anywhere / break-word` 는 쓰지 않는다 — 칸이 좁아지면 글자가 세로로 쌓인다.

### PC 대비 바뀌는 점과 근거

| 변화 | 근거 |
|---|---|
| **19px 단계가 사라진다** | 모바일에서 19는 페이지 제목으로는 작고 섹션 제목으로는 크다. 20(페이지) / 17(섹션)으로 갈라 역할을 분명히 한다. 현재 19px 은 측정 대상 21개 화면에서 104회 쓰이고 있어, 이 한 줄이 가장 큰 변경이다. |
| **목록 핵심 정보 15 → 16** | 목록이 보비 모바일의 주 화면이다. 한 단계만 올려 스캔 속도를 확보한다. |
| **배지·캡션 13 → 12** | 메타(13)와 배지(12)를 갈라야 2·3줄째가 구분된다. 단 랜딩 페이지(`styles/landing.css`)는 기존대로 13px 을 하한으로 둔다 — 로그인 전 화면이라 판독성 우선. |
| **입력 13–15 → 16 고정** | iOS Safari 는 16px 미만 입력에 포커스가 가면 화면을 자동 확대하고, 빠져나와도 되돌리지 않는다. 타이포 일관성보다 우선한다. |
| **주요 CTA 헤더 → 하단 FAB** | 한 손으로 쥐었을 때 화면 위쪽 오른편은 엄지가 닿지 않는다. 더해서 헤더에서 CTA 를 빼면 잔여 뱃지와 함께 2줄이던 헤더가 1줄로 줄어 `/charts/` `/unclaim/` 에서 첫 데이터가 46px 올라온다(실측). 스크롤을 내려도 따라오므로 목록 끝에서 되돌아갈 필요도 없다. |

## 1-2. 간격 · 여백

**모든 값은 4px 배수만 쓴다.** 1–3px 미세 조정도 쓰지 않는다.

| 항목 | 모바일 | 토큰 |
|---|---|---|
| 화면 좌우 여백 | 16 | `--m-gut` |
| 상단 바 아래 ~ 페이지 제목 | 16 | `--m-sp-bar-title` |
| 페이지 제목 ~ 첫 컴포넌트 | 12 | `--m-sp-title-first` |
| 섹션 사이 | 24 | `--m-sp-section` |
| 같은 그룹 안 — 밀접 / 일반 | 8 / 12 | `--m-sp-tight` / `--m-sp-group` |
| 카드·목록 행 안쪽 | 상하 12, 좌우 16 | `--m-row-pad-y` / `--m-row-pad-x` |
| 목록 행 사이 | 구분선 1px, 간격 0 | — |
| 행 안 정보 줄 사이 | 4 | `--m-sp-line` |
| 하단 고정 요소 | 높이 72 이하 + `env(safe-area-inset-bottom)` 반영 | `--m-h-bottombar` |
| 목록 아래 여백 (FAB 가림 방지) | 64 | `--m-list-pad-bottom` |

목록 행 사이는 "8px" 와 "구분선" 중 **구분선**으로 통일한다. 현재 모든 목록이 구분선을 쓰고 있고, 행 사이 간격을 주면 행 높이 96px 제한과 겹쳐 한 화면에 들어가는 행이 줄어든다.

Gestalt 비율: 그룹 내부 8 : 섹션 사이 24 = 1:3. PC(20:48 = 1:2.4)와 같은 성격을 유지한다.

## 1-3. 버튼 크기와 터치 범위

| 토큰 | 대상 | PC | 모바일 |
|---|---|---|---|
| `--m-tap-min` | 모든 탭 가능 요소 | — | **44×44** |
| `--m-h-btn-lg` | 주요 CTA — 하단 플로팅(FAB) | 40 (헤더 버튼) | **48** |
| `--m-h-btn-md` | 보조 버튼 (수정·삭제·바로가기·인쇄·답변) | 32–36 | **44**, 좌우 패딩 16 이상 |
| `--m-h-chip` | 필터 칩 · 탭 | 29–32 | 보이는 높이 **32**, 터치 범위 **44**, 최소 폭 44 |
| `--m-tap` | 검색바 안 기간·필터 아이콘 버튼 | 텍스트 버튼 | **44×44**, 아이콘 18 |
| `--m-icon-btn` | 아이콘 버튼 (햄버거·?·도움말·보내기) | 32×32 | **44×44** (아이콘 20–24) |
| `--m-h-input` | 입력창·검색창·선택상자 | 36–40 | **44** |
| — | 텍스트형 버튼 (기간 선택·전체보기·재전송) | 글자 높이 | 터치 범위 **44** |
| — | 페이지네이션 숫자 | 32×32 | **44×44** |
| `--m-tap-gap` | 인접 탭 요소 사이 | 6 | **8** 이상 |

보이는 크기와 터치 범위를 가르는 방법

```css
/* 칩은 32px 로 보이되 44px 로 눌린다 — 1-4 절제 기준과 충돌하지 않게 */
.pill { position: relative; min-height: var(--m-h-chip); }
.pill::after { content: ''; position: absolute; left: 0; right: 0;
               top: 50%; height: var(--m-tap-min); transform: translateY(-50%); }
```

입력창은 바깥 상자가 아니라 **`input` 자체**가 44px 을 채워야 한다. 현재 검색바는 상자 46px / 내부 input 26px 이다.

예외 — 본문 문장 안에 끼어 있는 인라인 링크(`display:inline`)는 44px 규칙에서 제외한다. 글줄 높이를 깨뜨리기 때문이다.

## 1-4. 절제 UI

측정 기준 화면 **375×740**, 확인 화면 **360×640**.

| 기준 | 값 |
|---|---|
| 첫 데이터(목록 첫 행)가 시작되는 위치 | **320px 이내** |
| 첫 화면에 온전히 보이는 목록 행 | **3개 이상** |
| 상단 바 높이 | 48–56 (현재 54 유지) |
| 상단 바 ~ 첫 데이터 사이 컴포넌트 합계 | **최대 270px** |
| 검색 + 필터 + 정렬 합계 | **최대 2줄 ≈ 100px** |

컴포넌트별

- **페이지 헤더** — 제목 1줄. 부제·통계는 아래 1줄(13px)까지. 아이콘 박스는 생략 가능.
- **주요 CTA** — **하단 플로팅 버튼(FAB)** 으로 둔다. 헤더에 넣지 않고, 전체 폭 단독 줄도 쓰지 않는다.
  - 대상은 그 화면에서 **새로 만드는 동작 하나**다 — 고객 추가 · 새 리포트 시작 · 새롭게 청구하기 ·
    새롭게 조회하기 · 새로운 상담하기 · 새롭게 작성하기.
  - 내보내기·인쇄처럼 **만들지 않는 보조 동작은 FAB 이 아니다.** 헤더 더보기 메뉴로 보낸다.
  - 규격 — 아이콘 + 짧은 라벨의 알약 형태, 높이 **48px**, 글자 16px,
    화면 오른쪽 아래 `right: 16px / bottom: 16px + env(safe-area-inset-bottom)`.
  - FAB 이 마지막 행을 가리므로 목록 아래에 **64px 이상** 여백을 준다.
  - 화면당 **1개**. 하단 액션 바가 있는 화면에는 FAB 을 두지 않는다(둘 중 하나).
  - 고정 요소 셈(아래)에서 **하단 1개**로 친다.
- **KPI·통계 카드** — 세로로 쌓지 않는다. 한 줄 요약(≤72px) 또는 가로 스크롤 1줄. 목록이 주 목적인 화면에서는 접힌 상태가 기본.
- **검색 · 기간 · 필터는 한 줄(44px)** — 검색창 오른쪽에 정렬·기간·필터를 붙인다. 필터가 한 줄을 통째로 쓰지 않는다.
- **기간 · 필터는 아이콘 버튼 44×44** — 라벨 없이 아이콘만 둔다. 달력·조절손잡이 아이콘은 그것만으로 읽히고,
  라벨을 달면 둘이 검색창을 밀어내 한 줄에 못 들어간다. `aria-label` 은 반드시 넣는다.
  - 고른 값이 있으면 **브랜드 색으로 채워** '적용됨' 을 표시한다 (`.has-value` / `.on`).
  - 필터 아이콘은 상단 바 햄버거와 겹치지 않게 조절손잡이(`#i-filter`)를 쓴다.
  - 누르면 바텀시트가 올라온다. 칩을 여러 줄로 펼치지 않는다.
- **보조 링크 버튼** — 목록 앞에 줄줄이 쌓지 않는다. 헤더 더보기 메뉴나 1줄 가로 스크롤로 모은다.
- **내비게이션** — 본문 상단 텍스트형 뒤로가기(`a.back-btn`, `a.back-link`)를 쓰지 않는다. 상단 바의 뒤로 버튼을 쓴다. 폼 하단의 "목록"·"취소" 버튼은 해당 없음.
- **스크롤 중 고정** — 상단 바 **1개** + 하단 액션 바 **1개**까지.
  - 상단: 상단 바만. 검색·필터는 한 줄로 축소된 형태일 때만 추가로 고정할 수 있다.
    제목·검색·필터를 겹겹이 고정해 데이터 볼 자리를 먹지 않게 하려는 조항이다.
  - 하단: 그 화면의 **주요 동작 하나**다 — 액션 바(저장 · 다음 · 결제) **또는** FAB(새로 만들기).
    둘을 함께 두지 않는다. 높이 **72px 이하**, `env(safe-area-inset-bottom)` 반영 필수.
    긴 폼에서 버튼을 찾으러 끝까지 스크롤하지 않게 하는 장치다.
  - 바텀시트·모달은 상시 고정 요소가 아니므로 이 셈에서 뺀다.

## 1-5. 데이터 표시

### 표기 형식

| 항목 | 표기 | 비고 |
|---|---|---|
| 생년월일 | `1968.06.19` | 입력 중 자동 포맷, `inputmode="numeric"` |
| 연락처 | `010-1234-5678` | 입력 중 자동 포맷, `type="tel"`. 저장 값 형식은 기존 유지 |
| 금액 | `1,234,567원` | 숫자와 "원" 사이 줄바꿈 금지, 오른쪽 정렬 |
| 날짜 / 일시 | `2026.11.27` / `2026.11.27 14:24` | 화면 간 통일 |
| 나이·성별 | `남 · 58세` | 구분자 `·` |

### 목록 행 구성

- 1줄째 — 왼쪽에 핵심 식별 정보(이름·제목), 오른쪽에 핵심 값(금액·상태).
- 2줄째 — 보조 메타 13px 한 줄. 넘치면 말줄임. 어절 중간 줄바꿈 금지.
- 3줄째(선택) — 배지 또는 날짜.
- **행 높이 3줄 기준 최대 96px.**
- 이름·금액·날짜·상태 배지는 `white-space: nowrap`, 이름 칸에는 한글 4자 최소 폭.
- 같은 정보를 한 행에서 두 번 보여 주지 않는다.

### 표

- 가로 스크롤 없이 화면 안에 맞춘다. 첫 열을 좁히고 줄바꿈을 허용한다.
- 맞추기 어려우면 카드형으로 바꾼다.
