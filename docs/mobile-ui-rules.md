# 보비 모바일 UI 적용 규칙

화면을 만들거나 고칠 때 옆에 두고 보는 문서. 2026-11-27 기준.

- 값이 왜 그렇게 정해졌는지 → [`mobile-design-standard.md`](mobile-design-standard.md)
- 지금 어디가 어긋나 있는지 → [`mobile-ui-audit-20261127.md`](mobile-ui-audit-20261127.md)
- 토큰 → [`../styles/tokens.mobile.css`](../styles/tokens.mobile.css) *(적용 전)*

다루는 것은 다섯 가지뿐이다 — 글자 / 간격 / 버튼·터치 / 절제 / 데이터.
색·둥글기·그림자·아이콘은 이 문서가 정하지 않는다.

## 0. 한눈에

```
글자   20 페이지제목 · 17 섹션 · 16 목록핵심/주요버튼/입력 · 15 본문
       14 보조버튼 · 13 메타 · 12 배지(최소)          ※ 19px 은 안 쓴다
간격   화면 16 · 섹션 24 · 그룹 12 · 밀접 8 · 줄 4     ※ 전부 4 배수
높이   CTA 48 · 버튼/입력 44 · 칩 32(터치 44) · 터치 최소 44×44
절제   첫 데이터 320 안 · 첫 화면 3행 · 검색+기간+필터 한 줄 · 고정 상단1+하단1
CTA    주요 동작은 하단 플로팅(FAB) 48 — 헤더에 넣지 않는다
행     3줄 · 96px 안 · 이름/금액/날짜 nowrap · 같은 정보 두 번 금지
```

## 1. 화면 조립 순서

### ① 상단 — 제목 줄

```
[아이콘 34] 페이지 제목 20px 1줄            [보조·더보기]
            설명 13px (최대 2줄, 말줄임)
```

- 제목은 **1줄**. 길면 제목을 줄이고 나머지는 설명 줄로 내린다.
- 설명·통계는 13px 한 줄. 두 줄 넘으면 `-webkit-line-clamp: 2`.
- **주요 CTA 를 헤더에 넣지 않는다.** 하단 플로팅(⑥)으로 보낸다.
  헤더 오른쪽에는 잔여 뱃지나 더보기 메뉴처럼 가벼운 것만 둔다.
- 아이콘 박스는 없어도 된다.
- **본문 상단에 "‹ 목록으로" 같은 텍스트 뒤로가기를 두지 않는다.** 상단 바의 뒤로 버튼을 쓴다.

### ② 검색 · 기간 · 필터 — **한 줄** (58px)

```
[🔍 검색 ..................  정렬 ▾  (📅) (⚙) ]   ← 한 줄. 아이콘은 44×44
```

- 검색 · 정렬 · 기간 · 필터를 **한 줄**에 넣는다. 필터가 한 줄을 통째로 쓰지 않는다.
- 기간·필터는 **아이콘만** 44×44. 라벨을 달면 둘이 검색창을 밀어내 줄이 넘어간다.
  - `aria-label` 필수 (`aria-label="기간 선택"`, `aria-label="필터"`).
  - 고른 값이 있으면 **브랜드 색으로 채운다** — `.period-trigger.has-value`, `.filter-trigger.on`.
  - 필터 아이콘은 `#i-filter`(조절손잡이). `#i-menu`(햄버거)는 상단 바와 겹쳐 안 쓴다.
- 마크업은 `.search-bar` **안에** 둔다. 밖에 두면 블록이 되어 한 줄을 다 먹는다.
- 필터 시트 동작은 `components/layout.js` 의 `bindFilterSheet()` 가 처리한다.
  `#filter-trigger` 와 `#filter-sheet` 만 있으면 자동으로 붙는다.
- **칩을 여러 줄로 펼치지 않는다.**

```html
<div class="search-bar">
  <span class="si-ic">…</span>
  <input type="text" id="search-input" placeholder="…" />
  <div class="sb-divider"></div>
  <div class="period-popover">
    <button class="period-trigger" id="period-trigger" aria-label="기간 선택" …>
      <svg><use href="#i-calendar"/></svg><span id="period-label">기간 선택</span><svg>…chevron…</svg>
    </button>
    …popup…
  </div>
  <button class="filter-trigger" id="filter-trigger" aria-label="필터" aria-controls="filter-sheet" …>
    <svg><use href="#i-filter"/></svg><span id="filter-label">필터</span><svg>…chevron…</svg>
  </button>
</div>
```

라벨(`<span>`)과 꺾쇠는 모바일에서 CSS 가 숨긴다. 데스크탑에서는 그대로 글자로 나온다.
- 보조 링크("보험사 연락처", "진단코드 검색" 등)를 목록 앞에 쌓지 않는다.
  헤더 더보기 메뉴나 한 줄 가로 스크롤로 모은다.

### ③ KPI · 통계

- **세로로 쌓지 않는다.** 한 줄 요약(72px 이하)이나 가로 스크롤 1줄.
- 목록이 주인 화면에서는 기본이 접힌 상태.

### ④ 목록

```
┌──────────────────────────────────────┐
│ 홍길동                     473,600원 │ ← 1줄 16px / 오른쪽 핵심값
│ 여 · 43세 · 010-1234-5678            │ ← 2줄 13px 말줄임
│ [동의 완료]              2026.06.09  │ ← 3줄(선택) 배지·날짜
└──────────────────────────────────────┘   행 높이 96px 안, 안쪽 12/16, 사이는 구분선
```

- **3줄까지, 96px 안.** 4줄째가 생기면 뭘 뺄지 정한다.
- 같은 정보를 한 행에서 두 번 쓰지 않는다. (예: 배지 줄 "06.10 발송" + 아래 "2026.06.10")
- 이름·금액·날짜·배지는 `white-space: nowrap`. 이름 칸은 한글 4자 최소 폭.
- 행 사이는 **구분선 1px**, 간격 0.
- 표 머리는 모바일에서 숨기고 행을 카드처럼 쓴다.

### ⑤ 폼

- `input` `select` `textarea` — 글자 **16px**, 높이 **44px**. 둘 다 예외 없다.
  16px 미만이면 iOS 에서 포커스 순간 화면이 확대되고 되돌아오지 않는다.
- 한 줄에 두 칸을 넣지 않는다. 모바일에서 `grid-template-columns: minmax(0, 1fr)`.
- 라벨 13px, 도움말 13px.

### ⑥ 하단 플로팅 버튼 (FAB) — 주요 CTA

```
                                        ┌──────────────┐
   … 목록 마지막 행 …                   │ ＋ 고객 추가 │ 48
                                        └──────────────┘
   목록 아래 64px 여백                    right 16 / bottom 16+safe
```

- 대상은 그 화면에서 **새로 만드는 동작 하나**.
  고객 추가 · 새 리포트 시작 · 새롭게 청구하기 · 새롭게 조회하기 · 새로운 상담하기 · 새롭게 작성하기.
- **내보내기·인쇄처럼 만들지 않는 보조 동작은 FAB 이 아니다.** 헤더 더보기 메뉴로.
- 아이콘 + 짧은 라벨의 알약 형태. 높이 48, 글자 16, 좌우 패딩 20. 폭은 **120px 안쪽**을 목표로 한다.
- 색·그림자는 각 화면의 기존 버튼 값을 그대로 쓴다 (이 규격의 범위 밖).
- 목록 아래에 **64px 여백** — 안 주면 마지막 행이 FAB 에 가린다.
- 화면당 1개. **하단 액션 바가 있는 화면에는 두지 않는다**(⑦의 하단 1개 자리를 나눠 쓴다).

**구현됨** — `styles/mobile-rules.css` 에 `.m-fab` 이 있다. 버튼에 클래스만 붙이면 된다.

```html
<!-- 데스크탑 마크업 그대로 두고 m-fab 만 추가. data-quota 등 동작이 유지된다 -->
<a class="new-rep-btn m-fab" href="new.html" data-quota="report">
  <svg class="ic-svg" width="16" height="16"><use href="#i-plus"/></svg>
  새 리포트<span class="m-fab-ext"> 시작하기</span>
</a>
```

- `m-fab-ext` 로 감싼 부분은 **모바일에서 접힌다**. 수식어("새롭게 ", " 시작하기")를 여기에 넣는다.
  접지 않으면 FAB 이 182px 까지 커져 목록을 절반 가린다.
- 푸터 여백은 `body:has(.m-fab) .ft` 가 알아서 잡는다. 따로 줄 필요 없다.
- 제목 오른쪽에 잔여 뱃지가 남는 화면은 `.hist-title-inner:has(.quota-pill) .ht-l` 규칙이
  제목에 한 줄을 통째로 줘서 제목이 두 줄로 밀리지 않게 한다. 역시 자동이다.

### ⑦ 하단 액션 바 (FAB 대신 쓸 때)

- 그 화면의 **주요 동작 하나**만. 저장 / 다음 / 결제.
- **72px 이하**, 한 줄 유지. 접혀서 2줄이 되면 기준 초과다.
- `env(safe-area-inset-bottom)` 반영 필수 — 안 하면 아이폰 홈 인디케이터에 가린다.

```css
/* 선례: pages/claim/sign-mobile.html .cta-bar */
.cta-bar {
  position: sticky; bottom: 0; z-index: 10;
  padding: 12px 20px calc(16px + env(safe-area-inset-bottom, 0px));
}
```

### ⑧ 스크롤 중 고정

- 상단 **1개**(상단 바) + 하단 **1개**(FAB **또는** 액션 바). 그 이상 고정하지 않는다.
- 검색·필터를 고정하려면 **한 줄로 줄인 상태**일 때만.
- 바텀시트·모달은 이 셈에서 뺀다.

## 2. 복붙 패턴

### 보이는 크기는 그대로, 터치만 44px

칩을 44px 로 키우면 화면을 먹는다. 보이는 건 32px 로 두고 눌리는 범위만 넓힌다.

```css
.pill { position: relative; min-height: 32px; }
.pill::after {
  content: ''; position: absolute;
  left: 0; right: 0; top: 50%;
  height: 44px; min-width: 44px;
  transform: translateY(-50%);
}
```

페이지네이션 숫자, 기간 선택 같은 텍스트형 버튼, 아이콘 버튼에 같은 방식을 쓴다.

### 한글 줄바꿈

```css
.bobi { word-break: keep-all; }        /* 어절 단위로만 끊는다 */
```

`overflow-wrap: anywhere` 와 `break-word` 는 **쓰지 않는다**. 칸이 좁아지면 글자가 한 자씩 세로로 쌓인다.

### 금액 · 날짜

```css
.amt { white-space: nowrap; font-variant-numeric: tabular-nums; text-align: right; }
```

`1,234,567원` 에서 숫자와 "원" 이 갈라지면 안 된다.
푸터·바닥글처럼 긴 줄에서는 항목마다 `<span class="ft-i">` 로 묶어 통째로 넘긴다.

### 1열로 접는 그리드

```css
@media (max-width: 960px) {
  .grid { grid-template-columns: minmax(0, 1fr); }   /* 1fr 아님 */
}
```

그냥 `1fr` 이면 자식의 최소 폭이 칸을 밀어내 화면 밖으로 넘친다.

### 가로로 넘칠 수 있는 것

```css
.scroll-x { overflow-x: auto; -webkit-overflow-scrolling: touch; }
.emain    { overflow-x: clip; }   /* hidden 은 안쪽 sticky 를 깨뜨린다 */
```

| | 대신 |
|---|---|
| `font-size: 19px` | 20(페이지 제목) 또는 17(섹션 제목) |
| `font-size: 0` 으로 글자 숨기기 | 아이콘 버튼 44×44 + `aria-label` |
| 입력 글자 13·15px | 16px |
| 4px 배수 아닌 간격 (14·10·18·6) | 12·16 / 8·12 / 16·20 / 4·8 |

## 4. 다 만든 뒤 체크리스트

375×740 과 360×640 두 폭에서 본다. 창만 줄이면 안 되고 **모바일 폭으로** 봐야 한다.

**글자**
- [ ] 20 / 17 / 16 / 15 / 14 / 13 / 12 외의 크기가 없다 (F1)
- [ ] 12px 미만이 없다 (F2)
- [ ] 입력·선택상자 글자가 16px 이상이다 (F3)
- [ ] 페이지 제목이 1줄이다 (F4)

**간격**
- [ ] 화면 좌우 여백 16px (S2)
- [ ] 목록 행 안쪽 상하 12 또는 16 (S3)
- [ ] 하단 고정 바에 safe-area 가 들어갔다 (S4)
- [ ] 패딩·마진·gap 이 4px 배수다

**버튼 · 터치**
- [ ] 누를 수 있는 것이 전부 44×44 이상이다 (본문 인라인 링크 제외) (B1)
- [ ] CTA 48 / 보조·입력 44 / 칩 32+터치 44 (B2)
- [ ] 인접한 탭 요소 사이가 8px 이상이다 (B3)

**절제**
- [ ] 목록 첫 행이 320px 안에서 시작한다 (R1)
- [ ] 첫 화면에 행이 3개 이상 온전히 보인다 (R2)
- [ ] 검색+기간+필터+정렬이 **한 줄**이다 (R3, 약 58px)
- [ ] 기간·필터 아이콘에 `aria-label` 이 있고, 값이 있으면 색으로 채워진다
- [ ] KPI 세로 적층이 없고, 주요 CTA 가 하단 플로팅이다 (R4)
- [ ] 고정 요소가 상단 1개 + 하단 1개(FAB 또는 액션 바) 이하다 (R5)
- [ ] FAB 이 있으면 목록 아래 64px 여백이 있다
- [ ] 본문 상단 텍스트형 뒤로가기가 없다 (R6)

**데이터**
- [ ] 생년월일 `1968.06.19` / 연락처 `010-1234-5678` / 금액 `1,234,567원` / 날짜 `2026.11.27` (D1)
- [ ] 이름·금액·날짜가 두 줄로 갈라지지 않는다. 어절 중간에서 끊기지 않는다 (D2)
- [ ] 목록 행이 3줄·96px 안이고 중복 정보가 없다 (D3)
- [ ] 표가 가로로 넘치지 않는다 (D4)
- [ ] 360 / 375 / 430px 어디서도 가로로 넘치지 않는다 (L1)

## 5. 측정하는 법

눈으로만 보면 놓친다. 실제로 쟀던 방법은 이렇다.

1. 페이지를 **폭 375 / 높이 740 짜리 iframe** 안에 넣는다.
   미디어쿼리가 iframe 폭에 반응하므로 창 크기와 상관없이 모바일 레이아웃이 나온다.
   (헤드리스 크롬의 `--window-size` 는 디스플레이 배율 때문에 그대로 먹지 않는다)
2. iframe 안에서 `getBoundingClientRect()` 와 `getComputedStyle()` 로
   글자 크기 · 요소 크기 · 첫 행 위치 · 고정 요소를 읽는다.
3. 가로 넘침은 `right > clientWidth` 인 요소를 모으되,
   **조상에 가로 스크롤 컨테이너가 있으면 뺀다** — 그건 밀어서 보는 영역이지 넘침이 아니다.
4. 4px 배수·토큰 미사용 글자 크기는 CSS 를 정적으로 훑어 파일·줄 번호로 뽑는다.

전체 점검을 다시 돌리는 스크립트가 필요하면 `tools/` 로 커밋해 둘 수 있다. 지금은 임시 폴더에만 있다.

## 6. 기존 규칙과의 관계

- PC 글자 4단계(24/19/15/13)와 간격 토큰(`--s1~--s10`)은 그대로다. 모바일만 따로 둔다.
- "11/12px 금지" 는 랜딩 페이지 규칙이다. 앱 화면은 배지에 한해 12px 을 쓴다. 랜딩은 13px 하한 유지.
- 현재 `styles/mobile-rules.css` 의 일부 값(`--m-row-y: 14`, `--m-gap-in: 10`, `--m-pad-sm: 14`, `--m-ic: 34`)은
  이 규칙보다 먼저 만들어져 4px 배수를 벗어난다. 각각 12 / 8·12 / 16 / 36 으로 바꾼다.
